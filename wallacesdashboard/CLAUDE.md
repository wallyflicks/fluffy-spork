This project is a personal life dashboard web app built with vanilla HTML/CSS/JS. No frameworks.

Tech stack:
- Vanilla HTML/CSS/JS only
- NO Next.js, NO TypeScript, NO React, NO Prisma, NO Tailwind, NO build steps
- Supabase JS via CDN: window.supabase.createClient(url, key)
- Vercel hosting, auto-deploys on push to main
- Lucide icons via CDN
- Chart.js via CDN
- PWA with sw.js service worker
- Vancouver timezone (America/Vancouver) for all dates
